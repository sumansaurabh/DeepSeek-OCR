================================================================================
TECHNICAL DETAILS
================================================================================

Root Cause:
- LlamaFlashAttention2 removed from transformers 4.51.0+
- DeepSeek-OCR model code (trust_remote_code=True) still imports it
- Similar issue in DeepSeek-VL2 (Issue #87)

The Fix:
- Wrap imports in try-except blocks
- Fall back to standard attention when unavailable
- Provide multiple solution paths for different use cases

Performance Impact:
- flash_attention_2: Fastest (when available)
- eager: Slightly slower but fully compatible
- Difference acceptable for most use cases
