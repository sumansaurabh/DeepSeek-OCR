TECHNICAL DETAILS
================================================================================

Architecture:
- Dataclass-based diagnostics storage
- Enum-based categorization
- Collector pattern for management
- Global singleton for easy access

Performance:
- Disabled by default (0% overhead)
- < 1% overhead when enabled
- One-time collection per layer (cached)
- Minimal memory footprint

Compatibility:
- Python 3.8+
- PyTorch 1.12+
- FlashAttention 1.x and 2.x
- vLLM 0.8.5+
- Fully backward compatible
